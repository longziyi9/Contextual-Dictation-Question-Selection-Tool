# Contextual-Dictation-Question-Selection-Tool
一个基于 Python 的图形化工具，可从 Excel 题库中按篇目抽取题目，并一键生成规范的 Word（.docx）或 PowerPoint（.pptx）试卷及答案文档。
✨ 功能亮点

📂 Excel 题库导入​ – 支持 .xlsx/ .xls文件，第一行为列标题（篇目、题干、答案A、答案B）。

🎯 灵活抽题​ – 勾选篇目、输入每篇抽取数量，支持顺序/乱序排列。

⚠️ 智能校验​ – 自动检测未勾选、数量超限等错误。

📄 双模式输出：

Word 模式​ – 标题黑体三号居中，正文宋体五号，1.5 倍行距，页边距 1.27cm。题目横线使用空格 + 下划线实现自动跨行（兼容 WPS）。答案中被替换的内容加下划线。

PPT 模式​ – 每页 5 道题，33×16cm 宽屏，华文中宋 24 号，左对齐。答案中被替换内容红色 + 下划线。

💾 自动保存​ – 默认保存到 C 盘根目录（权限不足时弹出另存为对话框）。

🚀 使用方法

运行程序

点击“浏览...”选择 Excel 题库文件。

勾选需要考查的篇目，并输入每篇抽取的题目数量。

选择排序方式（顺序 / 乱序）和输出模式（Word / PPT）。

点击“生成文档”，等待完成。

🔧 技术栈

Python 3.8+

Tkinter（GUI）

Pandas（Excel 读取）

python-docx（Word 生成）

python-pptx（PPT 生成）
